Editing and playback

The document is the music. Each $: or named pattern is shown as a row. Volume and mute edit its code. Solo, metronome, scale guide and viewing range are temporary.

The source piano roll edits one finite note() or s() literal across a 1, 2, 4 or 8 cycle view. Changing the view repeats existing notes without changing the code. Editing a repetition creates a native multi-cycle phrase; notes outside a smaller view are preserved. Repetition and effects outside that literal stay untouched. Dynamic mini notation is read-only here; edit it in the document. The playing-pattern overview shows the evaluated result.

Recording inserts across the selected editing view. Recording is available for a direct note() or s() pattern with no timing transforms except its editable length. Arbitrary Strudel still plays normally.

Strudel’s standard sample libraries and drum-bank aliases load automatically. Custom libraries can be added with samples() in the document. Code runs only when you press Apply or Play, in an isolated player without access to this editor’s storage. Only open code from people you trust: code can access the network and consume resources.
